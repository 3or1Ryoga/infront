# SlantButton リデザイン指示書

対象ファイル: `src/components/SlantButton.astro`

以下の3点を修正すること。コードを書く前に現在の実装を読み、
修正計画を報告してから実装に進むこと。

---

## 修正 1: 赤と黒の面積比を変更する

### 現状の問題
黒（墨色）の面積が大きすぎる。

### 修正仕様
赤（#B22222）と黒（#1A1A1A）の面積比を **8:2** にする。

```
修正前: [── 赤 70% ──/── 黒 30% ──]
修正後: [──── 赤 80% ────/─ 黒 20% ─]
```

clip-path の polygon 値を調整して実現すること。
斜線の角度は急角度（シャープ）を維持すること。

---

## 修正 2: ホバーアニメーションを「赤が消えて黒になるワイプ」に変更する

### 現状の問題
ホバー時に一瞬で全体が黒に変わる。チープ・ダサく見える。

### 修正仕様
ホバー時に **赤エリアが左から右へ徐々に消えていき、全体が黒になる** アニメーションにする。

```
アニメーションのイメージ（時系列）:

通常時:  [──── 赤 ────/─ 黒 ─]
途中①:  [── 赤 ──/─── 黒 ───]
途中②:  [─ 赤 ─/──── 黒 ────]
完了時:  [──────── 黒 ────────]
```

境界線（斜線）が左から右へスライドするように動き、
最終的にボタン全体が黒（#1A1A1A）になること。

### 実装方法
`clip-path` の polygon 値を CSS transition でアニメーションさせる。

```css
/* 通常時: 赤エリアが80%を占める */
.red-layer {
  clip-path: polygon(0 0, 82% 0, 76% 100%, 0 100%);
  transition: clip-path 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}

/* ホバー時: 赤エリアが左端に消える */
.slant-button:hover .red-layer {
  clip-path: polygon(0 0, 0% 0, 0% 100%, 0 100%);
}
```

ただし上記はあくまで参考値。
ボタン全体の構造（赤レイヤー・黒ベース）を踏まえて
最も自然に見える実装方法を選ぶこと。

`cubic-bezier(0.4, 0, 0.2, 1)` を使い、
アニメーションに加速・減速の緩急をつけること（linear 禁止）。

## 修正 3: ヒーローセクション用バリアントを追加する

### 現状の問題
ホバー時に全体が黒（#1A1A1A）になるため、
ヒーローセクション（背景も #1A1A1A）でボタンが背景に溶け込む。

### 修正仕様
Props に `variant` を追加し、2種類を実装する。

```typescript
interface Props {
  text:      string;
  href:      string;
  external?: boolean;
  variant?:  'default' | 'onDark'; // 追加
}
```

| variant | 使用場所 | 通常時 | ホバー完了時 |
|---|---|---|---|
| `default` | 白・薄背景の上 | 赤(80%) ＋ 黒(20%) | 全体が黒 |
| `onDark` | ヒーロー等の暗背景 | 赤(80%) ＋ **白**(20%) | 全体が**白** |

`onDark` はホバー完了時に全体が白（#FFFFFF）になることで、
暗背景の上でも消えずに視認できる。
アニメーションの動き（赤が左から消えていく）は両 variant 共通。

### 使用例
```astro
<!-- 白・薄背景のセクション（About / Products / Contact） -->
<SlantButton text="会社概要を見る" href="/company" />

<!-- ヒーローセクション（暗背景）-->
<SlantButton text="製品一覧を見る" href="/products" variant="onDark" />
```
