## PHASE 6: PDFカタログ・口頭情報から products.json を生成する
【クライアントからカタログ・製品情報を受け取ったタイミングで実施】

---

### パターンA: PDFカタログが届いた場合

以下のPDFカタログの内容を読み取り、products.json のスキーマに変換して。

【PDFをここに添付 or テキスト抽出してペースト】

読み取りルール:
- 製品名・品番・粒度・分析値・嵩比重を全製品分抽出すること
- 分析値が表形式で横展開されている場合は、
  analysis 配列（{ label, value }）に縦変換すること
- 読み取れなかった項目は null にすること（推測で埋めないこと）
- 単位（％、g/cm³ 等）が記載されていれば value に含めること
- カテゴリが明示されていない場合は製品の性質から
  「研削材料」「セラミックス原材料」「工業用副資材」のいずれかに分類すること

---

### パターンB: 口頭・メモで情報が来た場合

以下の製品情報を products.json のスキーマに変換して。

【ここに口頭でもらった情報をそのままペースト】
例:
- 製品名: 褐色アルミナ、品番: TBA、粒度: F16〜F220、Al2O3: 94.5%、嵩比重: 1.85
- ...

変換ルール:
- 化学式は正しい上付き・下付き表記に変換すること
  （例: Al2O3 → Al₂O₃、SiO2 → SiO₂）
- 単位が抜けている数値には適切な単位を補完すること
- 品番が不明な製品は id を「UNKNOWN-（連番）」とすること

---

### 共通ルール（A・B共通）
- 変換後の JSON を src/data/products.json に上書きすること
- JSON.parse でパースエラーが出ないか必ず確認すること
- 変換完了後、以下を報告すること:
  - 変換した総製品数
  - カテゴリごとの内訳
  - null になった項目がある製品とその理由
